Your free trial has ended — here's how to keep going for free

Groq — Fastest Free Option 30 sec setup

Free API key, no credit card. Runs Llama 3.1 at 500+ tokens/sec — faster than most paid APIs.

  1. Go to console.groq.com and sign up (Google/GitHub login)
  2. Click "API Keys" and create one
  3. Paste it in Settings > Cloud Providers > Groq API Key
  4. Select a Groq model from the dropdown — done!

Google Gemini — Free Tier 30 sec setup

1,500 free requests per day. Great for document generation.

  1. Go to aistudio.google.com/apikey
  2. Click "Create API Key"
  3. Paste it in Settings > Cloud Providers > Gemini API Key

Local Model — Fully Offline, Unlimited 5 min setup

No internet needed. Your data never leaves your machine.

  1. Go to Settings > Pull LLM Model
  2. Type phi4-mini (lightweight, works on any hardware) and click Pull
  3. For better quality with a GPU: llama3.1:8b
